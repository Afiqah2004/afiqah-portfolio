## 💻 Getting Started

To run the portfolio locally, make sure you have **Node.js** installed.

### 1. Clone the repository

```bash
git clone https://github.com/Afiqah2004/afiqah-portfolio.git
```

### 2. Open the project

```bash
cd afiqah-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Vite will provide a local development URL, usually:

```text
http://localhost:5173/
```

Open the URL in your browser.

## 🔧 Development Approach

The portfolio was developed using a component-based React architecture.

Reusable React components are used for major sections such as:

* Navigation
* Hero
* About
* Projects
* Skills
* Education
* Contact
* Footer
* Project details modal

Project information is maintained separately in `src/data/projects.js`, allowing project content to be updated without modifying the main application structure.
